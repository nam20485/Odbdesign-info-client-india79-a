## Project Overview

**OdbDesignInfo Client** is a professional-grade, cross-platform Avalonia desktop application for interrogating ODB++ PCB (Printed Circuit Board) designs. It operates as an intelligent analytics dashboard that consumes hierarchical design data from the **OdbDesignServer** backend.

### Target Audience

| Role | Use Case |
|------|----------|
| **CAM Engineers** | Verify drill charts and layer stackups |
| **PCB Designers** | Cross-probe specific nets and verify component footprints |
| **Test Engineers** | Locate test points and verify net continuity |

### Architecture

- **Pattern**: Client-Server topology with Clean Architecture
- **Client**: "Thin Client" logic with "Thick" UI capabilities (presentation, filtering, cross-probing)
- **Server**: OdbDesignServer handles parsing raw ODB++ files and serving normalized data

## Key Design Decisions

### Hybrid Connectivity
- **REST (HTTP/1.1)**: Used for "chatty" operations - fetching design lists, health checks
- **gRPC (HTTP/2)**: Used for "bulky" operations - streaming thousands of net/component records

### UI Framework Choice
Avalonia UI over MAUI because:
- Pixel-perfect rendering consistency across all platforms
- Native support for complex hierarchical DataGrids
- Better performance with virtualization for 10,000+ row grids

### MVVM Implementation
- `CommunityToolkit.Mvvm` with source generators reduces boilerplate
- ViewModels are `Transient`, Services are `Singleton`
- Core project has no Avalonia dependency (testable and portable)
